# MODBUS模块配置文件使用文档

## 概述

MODBUS模块是IOUI框架下的设备驱动模块，支持Modbus RTU和Modbus TCP两种通信协议。该模块能够读取数字量输入(DI)、模拟量输入(AI)，并支持数字量输出(DO)和寄存器写入功能。

**主要特性**：
- 🔌 支持Modbus RTU（串口）和Modbus TCP（网络）双协议
- 📊 支持多种数据类型：uint16, int16, uint32, int32, float32, fixed16_16
- 🔄 支持多字节序：AB(大端), BA(小端)
- 🎯 支持编码器专用格式：Q16.16固定点数
- 🚀 纯主动轮询模式，高效稳定
- 🔒 连接共享和线程安全设计
- 🎯 灵活的通道映射配置
- ✨ **数学表达式系统，配置更直观** 🎉
- 🔄 **自动断线重连，长期稳定运行** 🛡️

---

## 配置文件结构

配置文件为INI格式，位于`Config\MODBUS\config.ini`。

**基本结构**：
- `[default]` - 默认配置参数（可选）
- `[expressions]` - 表达式库（可选）
- `[device_N]` - 具体设备配置（N为设备索引号，从1开始）

**示例结构**：
```ini
# 默认配置（可选）
[default]
poll_interval_ms=100
command_interval_ms=10

# 表达式库（可选）
[expressions]
encoder_angle_10bit = x * 360 / 1024

# 设备1配置
[device_1]
driver=modbus_tcp
ip=192.168.1.100
# ... 其他配置

# 设备2配置
[device_2]
driver=modbus_rtu
port=1
# ... 其他配置
```

## 配置参数详解

### 1. 连接参数

#### 串口通信参数（Modbus RTU）
```ini
# 数据位 (默认: 8)
data_bit=8

# 停止位 (默认: 1) 
stop_bit=1

# 校验位 (默认: N)
# N-无校验, E-偶校验, O-奇校验
parity=N

# 波特率 (默认: 9600)
baud_rate=9600
```

#### 网络通信参数（Modbus TCP）
```ini
# IP地址
ip=192.168.1.100

# TCP端口号 (默认: 502)
port=502
```

#### 通用Modbus参数
```ini
# 从机地址 (默认: 1)
slave_addr=1

# 命令超时时间，单位ms (默认: 100)
timeout_ms=100

# 指令失败重试等待时间，单位ms (默认: 20)
retry_wait_ms=20
```

---

### 2. 轮询时序参数

```ini
# 轮询间隔(ms) - 每轮读取完成后的等待时间 (默认: 100)
# 控制数据刷新频率，值越小刷新率越高
# 快速响应场景：10-50ms
# 普通场景：100-200ms
# 慢速设备：500-1000ms
poll_interval_ms=100

# 命令间隔(ms) - 连续读取命令之间的间隔 (默认: 10)
# 防止设备响应不过来，值越大越稳定但刷新率越低
# 高速设备：5-10ms
# 普通设备：10-20ms
# 慢速设备：50-100ms
command_interval_ms=10

# 断线检测阈值 - 连续失败多少次判定为断线 (默认: 3，设为0则禁用断线重连)
# 设置太小(1-2)：偶尔丢包就判定断线，误判率高
# 设置太大(>10)：真正断线时检测慢，恢复时间长
# 推荐值：2-5次
# 计算公式：检测时间 ≈ max_consecutive_failures × (timeout_ms + poll_interval_ms)
# 示例：3次 × (100ms + 100ms) = 600ms 内检测到断线
# 禁用重连：设为0则完全禁用断线检测和重连机制
max_consecutive_failures=3
```

**性能计算示例**：
```
场景A：DI + AI单通道
poll_interval_ms=100, command_interval_ms=10
轮询周期 ≈ 100 + 10 + 10 = 120ms
刷新率 ≈ 8.3Hz

场景B：快速响应
poll_interval_ms=10, command_interval_ms=5
轮询周期 ≈ 10 + 5 + 10 = 25ms
刷新率 ≈ 40Hz
```

**断线检测时间计算**：
```
默认配置：max_consecutive_failures=3, timeout_ms=100, poll_interval_ms=100
断线检测时间 ≈ 3 × (100 + 100) = 600ms

快速检测：max_consecutive_failures=2, timeout_ms=50, poll_interval_ms=50
断线检测时间 ≈ 2 × (50 + 50) = 200ms

稳定配置：max_consecutive_failures=5, timeout_ms=200, poll_interval_ms=100
断线检测时间 ≈ 5 × (200 + 100) = 1500ms

禁用重连：max_consecutive_failures=0
完全禁用断线检测，即使连续失败也不会触发重连
```

```ini
# DI功能码 (默认: 0x02)
```

### 4. 模拟量输入(AI)配置 ✨

MODBUS模块采用**数学表达式系统**，让配置更直观灵活。

#### 配置格式

```ini
# 格式: ai_channel = 地址, 数据类型[, 表达式][, 字节序][, 功能码]
# 默认值: 表达式=x(不缩放), 字节序=AB(大端), 功能码=ai_func
```

**参数说明**：

| 位置 | 参数 | 必需性 | 默认值 | 说明 |
|------|------|--------|--------|------|
| 1 | 地址 | ✅ 必需 | - | 寄存器起始地址（十六进制，如0x0000） |
| 2 | 数据类型 | ✅ 必需 | - | uint16, int16, uint32, int32, float32, fixed16_16 |
| 3 | 表达式 | ⭕ 可选 | x | 数学表达式，x为原始值 |
| 4 | 字节序 | ⭕ 可选 | AB | AB(大端), BA(小端) - 仅对32位数据有效 |
| 5 | 功能码 | ⭕ 可选 | ai_func | 0x03(保持寄存器), 0x04(输入寄存器) |

#### 表达式系统 🎯

**三种表达式配置方式**：

1. **预定义表达式**（推荐，复用性好）
   ```ini
   ai_channel = 0x0000, uint32, encoder_angle_10bit
   ```

2. **内联表达式**（直观灵活）
   ```ini
   ai_channel = 0x0000, uint32, {x*360/1024}
   ai_channel = 0x0001, int16, {(x-1000)*0.1}
   ```

3. **直接表达式**（简洁）
   ```ini
   ai_channel = 0x0000, uint16, x*0.1
   ai_channel = 0x0001, int16, x*0.01+10
   ```

**支持的数学运算**：
- **运算符**：`+` `-` `*` `/` `^`（幂运算） `()`（括号）
- **函数**：`abs(x)` `sqrt(x)` `pow(x,y)` `sin(x)` `cos(x)` `tan(x)` `ln(x)` `log10(x)` `exp(x)` `floor(x)` `ceil(x)`
- **常量**：`pi()` `e()`

**表达式示例**：

| 应用场景 | 表达式 | 说明 |
|---------|--------|------|
| **编码器角度** | `x*360/1024` | 10bit分辨率编码器角度转换 |
| **温度传感器** | `(x-1000)*0.1` | PT100温度传感器，偏移1000，分辨率0.1℃ |
| **4-20mA信号** | `(x-4000)/16000*100` | 标准电流信号，量程0-100 |
| **线性校准** | `x*0.1+5` | 线性校准：缩放0.1倍，偏移5 |
| **非线性校准** | `x*x*0.001+x*0.5+10` | 二次校准曲线 |
| **三角函数** | `sin(x*pi()/180)*100` | 角度转正弦值（度转弧度） |
| **开方运算** | `sqrt(abs(x))*10` | 开方运算（流量计算） |

#### 单通道配置

使用 `ai_channel` 配置单个AI通道（等同于 `ai_channel_0`）：

```ini
# AI功能码（默认）
ai_func=0x04

# 示例1：最简配置 - 读取uint16（默认表达式 x，不缩放）
ai_channel = 0x0000, uint16

# 示例2：使用预定义表达式
ai_channel = 0x0000, uint32, encoder_angle_10bit

# 示例3：内联表达式 - 编码器角度转换
ai_channel = 0x0000, uint32, {x*360/1024}

# 示例4：温度传感器 - PT100校准
ai_channel = 0x0000, int16, {(x-1000)*0.1}

# 示例5：直接表达式 - 简单缩放
ai_channel = 0x0000, int16, x*0.1

# 示例6：复杂表达式 - 非线性校准
ai_channel = 0x0000, uint16, {x*x*0.001 + x*0.5 + 10}

# 示例7：小端序32位数据
ai_channel = 0x1000, float32, {x*1.5}, BA

# 示例8：完整配置
ai_channel = 0x1000, float32, {x*0.01+5}, BA, 0x03
```

#### 多通道配置

使用 `ai_channel_N` 配置多个AI通道：

```ini
# 通道0：状态字（最简配置）
ai_channel_0 = 0x0000, uint16

# 通道1：温度（使用预定义表达式）
ai_channel_1 = 0x0010, int16, temp_pt100

# 通道2：编码器位置（内联表达式）
ai_channel_2 = 0x0100, uint32, {x*360/1024}, BA

# 通道3：压力传感器（4-20mA信号）
ai_channel_3 = 0x0200, uint16, current_4_20ma

# 通道5：跳过通道4，直接配置通道5
ai_channel_5 = 0x0300, int16, {x*0.01+10}
```

### 5. 表达式库配置 📚

在 `[expressions]` 区段预定义常用表达式，提高配置复用性：

```ini
[expressions]
# 编码器角度转换（各种分辨率）
encoder_angle_10bit = x * 360 / 1024     # 10bit = 1024线，精度 0.35°
encoder_angle_12bit = x * 360 / 4096     # 12bit = 4096线，精度 0.088°
encoder_angle_13bit = x * 360 / 8192     # 13bit = 8192线，精度 0.044°
encoder_angle_2500 = x * 360 / 2500      # 2500线，常用于伺服电机

# 温度传感器
temp_pt100 = (x - 1000) * 0.1            # PT100 温度传感器
temp_ntc = x * 0.1 - 50                  # NTC 温度传感器

# 标准信号转换
current_4_20ma = (x - 4000) / 16000 * 100    # 4-20mA 标准信号
voltage_0_10v = x * 10 / 4096                # 0-10V 信号（12bit ADC）

# 位移传感器
displacement_mm = x * 0.01               # 位移传感器，单位0.01mm
displacement_um = x * 0.1                # 位移传感器，单位0.1μm

# 压力传感器
pressure_0_100bar = x * 0.01             # 压力传感器，量程0-100bar
pressure_mpa = x * 0.001                 # 压力传感器，输出MPa

# 流量计算
flow_sqrt = sqrt(abs(x)) * 0.1           # 差压式流量计（开方）
flow_linear = x * 0.001                  # 线性流量计

# 非线性校准
sensor_quadratic = x*x*0.001 + x*0.5 + 10    # 二次校准曲线
sensor_cubic = x*x*x*0.000001 + x*x*0.001 + x*0.1  # 三次校准曲线
```

**表达式库使用示例**：
```ini
[device_encoder]
# 使用预定义表达式，清晰易懂
ai_channel = 0x0000, uint32, encoder_angle_12bit
ai_channel_1 = 0x0002, int16, temp_pt100
ai_channel_2 = 0x0010, uint16, pressure_0_100bar

[device_flow]
# 流量计算
ai_channel = 0x0000, uint16, flow_sqrt
ai_channel_1 = 0x0001, int16, temp_pt100
```

### 6. 数据类型说明

| 类型 | 寄存器数 | 数值范围 | 字节序 | 说明 |
|------|---------|---------|--------|------|
| **uint16** | 1 | 0 ~ 65535 | - | 无符号16位整数 |
| **int16** | 1 | -32768 ~ 32767 | - | 有符号16位整数 |
| **uint32** | 2 | 0 ~ 4,294,967,295 | AB/BA | 无符号32位整数 |
| **int32** | 2 | -2,147,483,648 ~ 2,147,483,647 | AB/BA | 有符号32位整数 |
| **float32** | 2 | IEEE 754 | AB/BA | 32位浮点数 |
| **fixed16_16** | 2 | ±32767.999 | AB/BA | Q16.16固定点数（编码器专用）⭐ |

**字节序示例**：
```
寄存器值：[0x1234, 0x5678]

AB (大端序)：0x12345678
BA (小端序)：0x78563412
```

**fixed16_16 特殊说明** ⭐：
```
Q16.16 固定点数格式:
[符号位1][整数15位][小数16位]

示例值:
- 0x0007ADA7 = 7.678 (正数)
- 0x8007ADA7 = -7.678 (负数)
- 0x00010000 = 1.0
- 0x00008000 = 0.5

解算方式: value / 65536
适用设备: 海德汉编码器、多摩川编码器、部分位移传感器

配置示例:
ai_channel = 0x0000, fixed16_16           # 最简配置
ai_channel = 0x0000, fixed16_16, x*1000   # mm转μm (保留精度)
ai_channel = 0x0000, fixed16_16, x, BA    # 小端序设备
```

**重要**：所有AI数据最终会映射到`int32_t`类型(`-2,147,483,648~2,147,483,647`)，超出范围的值会被限制。

### 7. 数字量输出(DO)配置

```ini
# 写寄存器地址偏移，16进制格式 (默认: 0x0000)
# 实际写入地址 = 通道号 + do_addr
do_addr=0x0000

# 默认DO功能码 (默认: 5)
# 当通道250的值为0时使用此功能码
# 5 - 写单个线圈
# 6 - 写单个寄存器
do_func=5
```

**DO写入说明**：
- 通道0-239：普通DO通道
- 通道240-242：特殊命令通道
  - 240：功能码(1=写线圈5, 2=写寄存器6)
  - 241：写入地址
  - 242：写入数据
- 通道250：写入功能码覆盖
  - 为0时使用`do_func`配置
  - 非0时使用该值作为功能码

## 数据读取和写入

### 输入数据读取

#### 数字量输入(DI)
- 支持功能码01(读线圈)和02(读离散输入)
- 数据以位为单位，每个通道对应一个位状态
- 通过`GetDeviceDI`函数获取
- 后台线程自动轮询更新

#### 模拟量输入(AI)
- 支持功能码03(读保持寄存器)和04(读输入寄存器)
- 支持6种数据类型和2种字节序
- **支持数学表达式计算，预编译高性能**
- 自动溢出保护（限制在int32范围内）
- 通过`GetDeviceAD_INT`函数获取
- 后台线程自动轮询更新

### 输出数据写入

#### 数字量输出(DO)
- 支持写单个线圈(功能码05)和写单个寄存器(功能码06)
- 地址计算：实际地址 = 通道号 + do_addr偏移
- 支持动态切换功能码（通过通道250）
- 通过`SetDeviceDO`函数设置
- 异步写入队列，不阻塞主线程

## 性能优化

### 表达式系统性能

**预编译机制**：
- ✅ 表达式在设备打开时编译一次
- ✅ 运行时直接计算，性能损失 < 1%
- ✅ 支持表达式缓存，相同公式不重复编译
- ✅ 常量折叠优化，提高计算效率

**性能对比**：

| 计算方式 | 单次耗时 | 性能损失 | 说明 |
|---------|---------|---------|------|
| 直接乘法 | 0.01 μs | 0% | 原始方法 |
| 预编译表达式 | 0.02 μs | < 1% | 推荐方式 |
| 实时解析 | 10 μs | 1000倍 | 已避免 |

### 轮询效率

模块采用**纯主动轮询模式**，具有以下特点：
- ✅ 无无意义等待，CPU利用率高
- ✅ 时间完全可控，易于调优
- ✅ 逻辑简单清晰，维护性好

**性能对比**：

| 配置 | 轮询周期 | 刷新率 | 工作效率 |
|------|---------|--------|---------|

## 注意事项与最佳实践

### 1. 表达式配置最佳实践 ✨

**优先使用预定义表达式**：
- ✅ **推荐**：定义在 `[expressions]` 中，多设备复用
- ✅ **好处**：可读性好、维护方便、统一管理

**内联表达式适用场景**：
- ✅ **简单计算**：`{x*0.1}`, `{x*360/1024}`
- ✅ **一次性使用**：不需要复用的特殊计算
- ✅ **调试阶段**：快速验证表达式正确性

**复杂表达式设计原则**：
- ✅ **使用括号明确优先级**：`{(x-1000)*0.1}` 而不是 `{x-1000*0.1}`
- ✅ **避免除零错误**：使用 `abs(x)` 或添加小数值
- ✅ **注意数值范围**：最终结果应在 int32 范围内

**表达式调试技巧**：
```ini
# 调试时可以先用简单表达式验证数据读取
ai_channel = 0x0000, uint16, x

# 然后逐步添加计算
ai_channel = 0x0000, uint16, {x*0.1}

# 最后使用完整表达式
ai_channel = 0x0000, uint16, {(x-1000)*0.1}
```

### 2. 断线检测配置最佳实践 🛡️

**根据网络质量调整阈值**：
- ✅ **稳定网络**：`max_consecutive_failures=2`（快速检测，200-400ms）
- ✅ **普通网络**：`max_consecutive_failures=3`（默认，平衡误判和检测速度）
- ✅ **不稳定网络**：`max_consecutive_failures=5`（降低误判，1-1.5秒）
- ✅ **禁用重连**：`max_consecutive_failures=0`（完全禁用断线检测）

**快速响应场景**：
```ini
# 编码器、运动控制等需要快速检测断线的场景
poll_interval_ms=10
timeout_ms=50
max_consecutive_failures=2
# 断线检测时间 ≈ 2 × (50 + 10) = 120ms
```

**稳定性优先场景**：
```ini
# 环境监测、数据记录等允许较长检测时间的场景
poll_interval_ms=100
timeout_ms=200
max_consecutive_failures=5
# 断线检测时间 ≈ 5 × (200 + 100) = 1500ms
```

**禁用重连场景**：
```ini
# 测试环境或不需要自动重连的场景
max_consecutive_failures=0
# 完全禁用断线检测和重连功能
```

### 3. 数据类型选择指南

**16位数据**：
- ✅ `uint16`：状态字、计数值、百分比
- ✅ `int16`：温度、压力、带符号测量值

**32位数据**：
- ⚠️ **必须确认字节序**：查看设备手册或测试验证
- ✅ `uint32`：编码器值、累计量、大数值
- ✅ `int32`：带符号的大数值
- ✅ `float32`：精密测量、科学计算

**编码器专用**：
- ⭐ `fixed16_16`：Q16.16格式编码器（海德汉、多摩川等）

### 4. 字节序确认方法

**测试验证法**：
```ini
# 先用默认大端序读取
ai_channel = 0x0000, uint32

# 如果数据明显错误，尝试小端序
ai_channel = 0x0000, uint32, x, BA

# 对比两种结果，选择正确的配置
```

**经验规律**：
- ✅ **大端序（AB）**：大部分PLC、仪表（约70-80%）
- ✅ **小端序（BA）**：PC类设备、部分编码器

### 5. 表达式库管理建议

**按功能分类组织**：


**版本控制**：
- ✅ 在注释中记录表达式的来源和版本
- ✅ 重要表达式变更前先备份
- ✅ 添加单位和量程说明

### 6. 性能调优

- 根据实际需求调整`poll_interval_ms`和`command_interval_ms`
- 平衡刷新率和设备负载
- 复杂表达式优先使用预定义方式，提高缓存命中率

### 7. 断线重连机制 🛡️

- ✅ 自动检测断线（基于`max_consecutive_failures`配置）
- ✅ **智能失败判定**：只有全部读取失败才计数，部分成功不计入失败 🎯
- ✅ 自动尝试重连（每5秒一次）
- ✅ 断线时自动清空写队列，避免积压
- ✅ 断线时`GetDeviceAD/DI`返回0（无新数据）
- ✅ 重连成功后自动恢复正常工作
- ✅ **可完全禁用**：设置 `max_consecutive_failures=0`

**失败判定逻辑说明**：
```
场景1：配置了DI + 3个AI通道
- DI读取失败，AI全部成功 → 不计入失败（有成功）✅
- DI读取成功，部分AI失败 → 不计入失败（有成功）✅
- DI和AI全部失败 → 计入失败 +1 ⚠️

场景2：只配置了AI
- 部分AI成功，部分失败 → 不计入失败（有成功）✅
- 全部AI失败 → 计入失败 +1 ⚠️

优势：降低误判率，容忍部分通道偶发错误
```

## 调试建议

### 基本检查清单
1. ✅ 验证连接参数（串口号、波特率、IP地址、端口）
2. ✅ 确认从机地址设置正确
3. ✅ 检查功能码是否与设备支持的功能匹配
4. ✅ 验证寄存器地址范围
5. ✅ 确认数据类型和字节序（32位数据特别注意）
6. ✅ 验证表达式语法正确（括号匹配、函数拼写）

### 表达式调试方法

**分步验证法**：
```ini
# 第1步：验证原始数据读取
ai_channel = 0x0000, uint16, x

# 第2步：验证简单计算
ai_channel = 0x0000, uint16, {x*0.1}

# 第3步：验证完整表达式
ai_channel = 0x0000, uint16, {(x-1000)*0.1}
```

**常见表达式错误**：
- ❌ 括号不匹配：`{x-1000*0.1` 缺少结束括号
- ❌ 函数拼写错误：`squrt(x)` 应为 `sqrt(x)`
- ❌ 除零风险：`{x/y}` 当y=0时出错，应为 `{x/(y+0.001)}`
- ❌ 数值溢出：结果超出 int32 范围被截断

### 常见问题排查

**问题1：无法连接设备**
- 检查物理连接和驱动
- 验证IP地址和端口（TCP）
- 验证串口号和波特率（RTU）

**问题2：读取数据为0或错误**
- 确认寄存器地址正确
- 检查功能码是否支持
- 验证数据类型和字节序

**问题3：表达式计算结果错误**
- ⚠️ 验证表达式语法（使用简单表达式如 `x*0.1` 测试）
- ⚠️ 检查原始数据是否正确（先用 `x` 查看原始值）
- ⚠️ 确认计算公式无误（手动验证几个样本值）
- ⚠️ 注意运算优先级（使用括号明确优先级）

**问题4：数据跳变或不稳定**
- 增大`command_interval_ms`
- 增大`timeout_ms`
- 检查网络或串口稳定性
- 检查表达式中是否有除零等不稳定因素

**问题5：刷新率太低**
- 减小`poll_interval_ms`
- 减小`command_interval_ms`
- 减少读取的寄存器数量
- 简化表达式计算

**问题6：32位数据错误**
- ⚠️ 检查字节序配置（AB或BA）
- ⚠️ 小端序设备必须明确指定BA
- ✅ 使用设备文档确认字节序

**问题7：编码器数据不正确（fixed16_16）** ⭐
- ⚠️ 确认设备是否使用Q16.16格式（查看手册）
- ⚠️ 检查字节序（AB或BA）
- ⚠️ 验证示例值：`0x0007ADA7` 应解析为 `7.678`
- ✅ 使用表达式保留精度：`fixed16_16, {x*1000}`（mm→μm）

**问题8：频繁误判断线**
- ⚠️ 增大`max_consecutive_failures`（如从3改为5）
- ⚠️ 检查网络稳定性或串口质量
- ⚠️ 增大`timeout_ms`，给设备更多响应时间
- ✅ 考虑禁用重连：`max_consecutive_failures=0`

**问题9：断线检测太慢**
- ✅ 减小`max_consecutive_failures`（如从5改为2）
- ✅ 减小`timeout_ms`和`poll_interval_ms`
- 📝 计算公式：检测时间 ≈ max_consecutive_failures × (timeout_ms + poll_interval_ms)
